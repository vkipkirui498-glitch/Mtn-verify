MoMo Demo Verification UI
==========================

This is a local-only, clearly labeled demo project.

How to use:
1. Unzip the archive.
2. Open index.html in a browser.
3. Use the sample test number 0700000000.
4. Enter any five digits for the dummy PIN and six digits for each dummy OTP.
5. On the waiting screen, use the simulated approval panel to test Approve Demo and Decline Demo.

Safety/technical notes:
- This project does not contact MTN, verify accounts, or send data to Telegram.
- PIN and OTP digits are cleared and are not transmitted or stored.
- The approval panel simulates the Telegram buttons locally. Real Telegram integration should be added only for non-sensitive demo status/session messages, never real PINs or OTPs.
- This is not production authentication software.
